# Jev Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Jev Lab, a premium dark-first experimentation environment for the Jev/TypeSafe API, verified against the live API.

**Architecture:** Next.js 14 App Router; frontend calls same-origin `/api/jev`, which attaches `TYPESAFE_API_KEY` server-side and proxies to `POST https://api.typesafe.ai/v1/systemone`. Visualization layer renders Noul/Choice/Score distributions; zustand+localStorage persists lab state.

**Tech Stack:** Next.js 14, TypeScript, Tailwind, Framer Motion, Recharts, Monaco, lucide-react, zustand, vitest.

**Spec:** User build prompt §§1–47 (this conversation).

## Global Constraints

- Never expose `TYPESAFE_API_KEY` to the browser; proxy via Next.js API routes.
- Follow the verified wire protocol: `{model, state, questions:{key:{type,instructions,criteria?}}}`; noul→`{noul}`, choice→`{choice,probabilities,confidence}`, score→`{score,legend,probabilities,confidence}`.
- Dark-first Linear/Vercel-grade UI; restrained color (probability/uncertainty/error/selection only).
- Demo mock output must always be labeled DEMO DATA.
- Language: "Jev assessment", "highest probability option", "observed difference" — never certainty or causality.
